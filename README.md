# Go to Project Eclipse Plug-in

Go to Project quickly selects a workspace project in Project Explorer or Package Explorer. Closed projects remain searchable and are opened when selected.

## Eclipse update site

<https://codingphil.github.io/go-to-project-eclipse-plugin/updatesite>

Go to Project 2.0.0 is available at this URL. The historical unsigned 1.x artifacts remain available so existing installations can update in place.

## Go to Project 2.0.0

Version 2.0.0 requires Eclipse IDE 2026-06 (Platform 4.40), or a compatible later Eclipse 4.x release, and Java 21. It includes null-safe handling for uninitialized explorers, deterministic project selection and focus, and safe handling of closed projects.

The 2.0.0 feature and plug-in JARs are unsigned. Eclipse 2026-06 is therefore expected to show a trust prompt for unsigned content during installation or update; review and accept that prompt to continue.
